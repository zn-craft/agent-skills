# 业务模式：数据表格

适用：有查询条件、分页、排序、行选择和批量操作的管理后台列表。

## 先确定状态归属

| 数据 | 常见归属 | 判断依据 |
|---|---|---|
| 搜索条件、页码、排序 | URL 或页面状态 | 是否需要分享、刷新恢复和前进后退 |
| 表格远端数据 | Query / 路由数据层 | 缓存、请求、失效和加载状态属于服务端数据机制 |
| 当前选中行 | 页面或表格 UI 状态 | 跨分页是否保留选择由业务决定 |
| 列显示、密度偏好 | 本地偏好状态 | 是否需要持久化由产品需求决定 |
| 编辑草稿 | 编辑表单所有者 | 与服务端查询结果分离 |

## 推荐决策

1. **查询条件与结果分开**：条件是输入，结果是服务端状态；不要再复制一份远端列表到全局 Store。
2. **选择优先存 ID**：通常保存 `Set<RowId>`，避免保存过期对象。跨页选择需明确 ID 生命周期与“全选”的语义。
3. **重置行为明确**：筛选条件改变时是否回到第一页；排序改变是否清除选择；由产品规则决定，不要隐含在多个 Effect 中。
4. **分页与虚拟化分工**：分页控制数据范围；虚拟化控制已加载数据的 DOM 数量。大数据量时可组合使用。
5. **列配置有边界**：稳定列配置可放模块作用域；依赖 Props / 权限的列配置再在组件中构造。不要为普通列数组机械使用 `useMemo`。
6. **状态反馈完整**：区分首次加载、后台刷新、无结果、请求失败和无权限；空结果不是错误。
7. **批量操作考虑部分失败**：明确全成功、部分成功、全失败后的选择保留、提示和刷新策略。

## 案例：跨页选择后批量归档

本例约定翻页保留选择，表头全选只作用于当前页可选行。换筛选时清空选择并回到第一页。批量提交允许部分成功。

| 事件 | 状态怎么变 |
|---|---|
| 勾选当前页或取消勾选 | 按行 ID 更新页面的 `selectedIds`。表头的选中和半选从当前页可选 ID 算出，总选中数取 `selectedIds.size`。 |
| 翻页、改筛选 | 翻页只改页码。提交筛选时，在同一个事件里更新筛选、页码和选择。请求层继续持有各页数据。 |
| 提交归档 | 提交时快照已选 ID。请求期间禁用重复提交、选择和筛选变更，分页仍可用。 |
| 收到结果 | 移除明确成功的 ID，保留失败项并展示原因。刷新受影响的查询。请求中断、结果不明时，先核对服务端状态，再决定是否重试。 |

切换当前页选择时，其他页的 ID 留在集合里。收到批量结果后只移除服务端确认成功的 ID。

```tsx
function selectPage(checked: boolean) {
  setSelectedIds((previous) => {
    const next = new Set(previous);
    for (const id of selectablePageIds) {
      if (checked) next.add(id);
      else next.delete(id);
    }
    return next;
  });
}

function applyArchiveResult(succeededIds: readonly RowId[]) {
  setSelectedIds((previous) => {
    const next = new Set(previous);
    for (const id of succeededIds) next.delete(id);
    return next;
  });
}
```

### 验收

1. 第一页选 A、B，第二页选 C。取消第二页全选后，A、B 仍被选中。
2. 再选 C 并提交。A、C 成功，B 失败。刷新后只保留 B，提示部分失败。重试时只提交 B。
3. 改筛选后回到第一页，已选计数归零。当前页可选行为空时，表头不显示为全选。

做有无 skill 的对照时，给两组同一份现有分页表格、上述业务约定和验收步骤。分别记录行为是否通过、是否引入重复状态、是否扩大改动。实现片段留作评审参考。

## 常见误区

- 把表格所有状态都放进全局 Store。
- 把服务端 rows 和编辑草稿混为一份可变对象。
- 用数组索引作为行 key 或选中标识。
- 用多个 Effect 相互同步筛选、页码和请求参数。
- 未定义跨页全选、筛选后选择保留等业务语义。
- 为了抽象而创建覆盖所有表格需求的万能 DataTable。

## 需要向产品 / 用户确认的业务问题

- 筛选条件是否进入 URL？
- 页码切换后是否保留已选行？
- “全选”是当前页、当前筛选结果，还是全部数据？
- 批量操作允许部分成功吗？

## 适用边界

纯展示、数据量很小的简单表格不需要复杂状态层。服务端分页、虚拟滚动、树形表格和可编辑表格应分别扩展，不要强行塞进同一个抽象。
